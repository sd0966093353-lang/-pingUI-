IPv4 標頭格式 (IPv4 Header Format — 32 bits per row)
依據 RFC 791 規範，每橫列固定 32 位元 (4 位元組)，共 5 列標準標頭 (20 位元組)
0123 4567 891011 12131415 16171819 20212223 24252627 28293031
VER 4 bits 4
HLEN 4 bits 5 (20B)
Service type 8 bits 0x00
Total length [連動計算] 16 bits 60 Bytes (0x003C)
Identification 16 bits 0x4E21
Flags 3 bits 010 (DF)
Fragmentation offset 13 bits 0
Time to live [指定] 8 bits 64 (0x40)
Protocol 8 bits 1 (ICMP)
Header checksum [連動計算] 16 bits 0x0000
Source IP address [自動偵測] 32 bits 172.16.70.129
Destination IP address [使用者指定] 32 bits 8.8.8.8 (0x08080808)
Options + padding (0 to 40 bytes) — [標準 Ping 封包無選項，長度為 0 位元組]
Total Length (總長度) 即時連動計算
Total Length = 20(IP) + 8(ICMP) + 32(Data) = 60 Bytes

當您在左側調整 Data 長度 時，IPv4 總長度欄位將自動累計「20 位元組 IPv4 標頭」與「8 位元組 ICMP 標頭」，並轉為 16-bit 填入標頭第 16~31 位元。

Header Checksum (標頭校驗和) RFC 791 運算
Checksum = ~[ Σ(16-bit Words) ] = 0x....

當 TTL、目的地 IP、Data 長度（影響總長度） 任一被更改時，程式將標頭拆分為 10 個 16-bit Words 進行反相累加 (Ones' complement sum) 即時更新校驗和。
